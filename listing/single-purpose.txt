Purpose: Let the user pause or resume HTML audio and video in the most recently playing Chrome tab with an optional global keyboard shortcut.

Permissions:
- storage: Keep temporary tab, document, media playback and pause state for the current browser session so the shortcut works if the Manifest V3 service worker restarts.
- webNavigation: Forget a tab's old media records after its main document navigates.
- HTTP and HTTPS content script matches: Observe standard HTMLMediaElement playback events and pause/resume media in the page the user is currently using.

Data handling: The extension reads the page title and HTML audio/video playback state, keeps that state in chrome.storage.session for the active browser session, and does not send it to a server or use analytics.
