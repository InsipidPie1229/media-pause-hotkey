Purpose: Let the user pause or resume HTML audio and video in the most recently playing Chrome tab, and adjust its volume and playback speed, with optional global keyboard shortcuts.

Permissions:
- storage: Keep temporary tab, document, media playback and pause state for the current browser session so the shortcut works if the Manifest V3 service worker restarts, and one local preference (whether the optional extension volume, a separate 0-500% gain layer that never changes the site's own volume, is turned on).
- webNavigation: Forget a tab's old media records after its main document navigates.
- scripting: Inject the same content observer into already-open HTTP and HTTPS tabs at install, browser startup, and before reading or controlling media. This recovers missed events and checks actual playback without requiring a page refresh.
- HTTP and HTTPS content script matches: Observe standard HTMLMediaElement playback events and pause/resume media or set its volume and playback speed in the page the user is currently using.

Data handling: The extension reads the page title and HTML audio/video playback state, keeps that state in chrome.storage.session for the active browser session, and does not send it to a server or use analytics.
