Privacy Policy — Media Shortcut

Last updated: October 8, 2026

Media Shortcut is a Chrome extension that lets you pause and resume standard HTML audio and video in the most recently playing tab.

Information processed

To provide this feature, the extension processes the page title, the source URL of standard audio and video elements, their playback state, and temporary Chrome tab, document, frame, and media identifiers. It does not read the media stream or the page body.

How information is used and stored

This information is used only to identify the tab with the most recently active media and to pause or resume the relevant media when you use the shortcut or popup. Temporary state is kept locally in Chrome's storage.session for the current browser session. Records for navigated or closed tabs are removed, and session data is cleared by Chrome's session lifecycle.

Local diagnostics

The extension keeps up to 200 recent diagnostic records (100 command/error records and 100 observation records) locally in storage.session to help investigate missed media detection. They contain temporary tab/document/frame/media identifiers, event and playback-transition information, error codes, and durations, but no page titles or URLs. Records are not sent to any server. The popup copies them to your clipboard only when you choose Copy diagnostics; if copying is unavailable, the text is shown for manual copying.

Sharing, advertising, and analytics

The extension does not send this information to the developer or other servers, and does not sell or share it with third parties. It does not use analytics, advertising, profiling, or human review.

Other data

The extension does not request or process personal identification, health, financial, authentication, communications, or location information.

Contact

For questions about this policy, use the developer support contact shown on the Media Shortcut Chrome Web Store listing.

Hosting of this policy page

This policy page is hosted on GitHub Pages. GitHub may process visitor IP addresses for security purposes under its Privacy Statement. This hosting activity is separate from the extension, which does not transmit extension data to GitHub.

미디어 단축키 개인정보처리방침

최종 수정일: 2026년 10월 8일

미디어 단축키는 Chrome에서 최근 재생한 탭의 표준 HTML 오디오와 영상을 일시정지하거나 다시 재생하는 확장 프로그램입니다.

처리하는 정보

기능 제공을 위해 페이지 제목, 표준 오디오·비디오 요소의 소스 URL과 재생 상태, 임시 Chrome 탭·문서·프레임·미디어 식별자를 처리합니다. 미디어 스트림이나 페이지 본문은 읽지 않습니다.

정보 이용과 저장

이 정보는 최근 재생 미디어가 있는 탭을 찾고, 사용자가 단축키나 팝업을 사용할 때 해당 미디어를 일시정지하거나 재개하는 데만 사용합니다. 임시 상태는 현재 브라우저 세션 동안 Chrome의 storage.session에 로컬로 보관합니다. 이동했거나 닫힌 탭의 기록은 제거되며, 세션 데이터는 Chrome 세션이 끝날 때 삭제됩니다.

로컬 진단 기록

미디어 인식 누락을 조사하기 위해 최근 진단 기록 최대 200건(명령·오류 100건, 관측 100건)을 storage.session에 로컬로 보관합니다. 임시 탭·문서·프레임·미디어 식별자, 이벤트와 재생 상태 전환, 오류 코드, 소요 시간을 포함하며 페이지 제목과 URL은 포함하지 않습니다. 서버로 전송하지 않습니다. 사용자가 팝업에서 ‘진단 기록 복사’를 누른 경우에만 클립보드로 복사하며, 복사할 수 없으면 직접 복사할 텍스트를 표시합니다.

제공·광고·분석

확장 프로그램은 이 정보를 개발자나 다른 서버로 전송하지 않으며, 제3자와 공유하거나 판매하지 않습니다. 분석, 광고, 프로파일링 또는 사람의 열람에도 사용하지 않습니다.

기타 정보

개인 식별 정보, 건강·금융 정보, 인증 정보, 개인 통신 또는 위치 정보는 요청하거나 처리하지 않습니다.
